# Posteingang-KI

Dokumenten-Triage für Versicherungen. Eine Streamlit-App, die eingehende
Versicherungsdokumente per LLM klassifiziert, Kernfelder extrahiert und
unsichere Fälle regelbasiert an eine menschliche Prüfung eskaliert.

**Status: in Entwicklung.** Diese README wird zum Abschluss durch eine
vollständige Version mit Screenshot, Architektur und Beispielrechnung ersetzt.

## Stack

Python 3.13 · Streamlit · pandas · pydantic · Anthropic SDK (Claude Haiku 4.5)

## Daten

Ausschließlich synthetische, selbst erstellte Beispieldokumente.
Keine echten Personen- oder Unternehmensdaten.
